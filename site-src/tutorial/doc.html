Doc comments

Unlike normal comments, doc comments begin with a | instead of #.

main void() info log "{1 foo}" | Returns twice as much as {x}. | A doc comment can also reference types like {nat}, | functions like {main}, | or even a spec like {equal}. foo nat(x nat) x * 2

Doc comments use the same interpolation syntax as string literals.
The interpolated names can refer to any kind of entity, such as a function, type, or spec. The compiler will check that they are valid.

It's a compile error to use a doc comment where it isn't expected, like on a local variable.
